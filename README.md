# Sistema de Prevenção contra a Violência nas Escolas

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do Trabalho AEP e tem como objetivo propor a construção de um sistema para prevenção da violência nas escolas.

O sistema busca auxiliar na identificação de situações de risco, registro de incidentes e comunicação entre alunos, professores, coordenadores, responsáveis e profissionais de apoio.

## 🎯 Objetivo Geral

Desenvolver um sistema para a prevenção da violência nas escolas, permitindo a identificação de riscos e a implementação de intervenções adequadas, contribuindo para um ambiente escolar mais seguro e acolhedor.

## ⚙️ Principais Funcionalidades

- Registro de incidentes de violência;
- Consulta e geração de relatórios;
- Sistema de alertas para situações de risco;
- Comunicação com serviços de apoio;
- Registro de ações preventivas;
- Identificação e acompanhamento de situações de risco.
